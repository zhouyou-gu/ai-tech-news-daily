Private AI Compute adds encrypted persistent memory

September 23, 2026Fresh signal · two-day-old architecture update

Trend / relevance: Cross-device continuity is becoming a platform capability, while the design makes authenticated channels, isolated execution and protected state explicit.

Google outlined secure server-side memory for its Private AI Compute platform so assistants can preserve useful state across devices without reverting to an ordinary cloud datastore. The architecture treats memory, attestation and access control as one systems surface.

Why it matters: Persistent agent memory changes the threat model and the communication budget: state now needs lifecycle controls, encrypted transport and verifiable deletion as well as retrieval quality.

1. Semantic Prism demonstrates multiuser SemCom on one RF chain

SemComHigh priorityarXiv preprint + hardware prototypeSeptember 23, 2026

Timeliness: Fresh signal · submitted inside the active research window

Trend / relevance: Direct high-priority fit plus a field-tested 400-element metasurface and seven-user result.

Semantic Prism jointly maps independent semantic representations and channel state to a common symbol stream plus discrete metasurface configurations. A 3.5 GHz prototype with two-bit phase control concurrently served up to seven users and improved semantic reconstruction over the reported baselines.

Why it matters to the group: It connects task-level representations to a constrained physical layer with real hardware, creating a rare path from semantic objective to multiuser radio control.

Follow-up: Replication — reproduce a two-user version in simulation, then plot semantic distortion against CSI error, phase quantization and user count.

5. Exact consensus under noisy links uses a decaying anchor

Wireless & NetworkingHigh priorityarXiv theory paperSeptember 23, 2026

Timeliness: Fresh signal · submitted this week

Trend / relevance: The analysis resolves persistent variance in stochastic-approximation consensus with an interpretable local mechanism.

Standard diminishing-step consensus can converge to an unbiased random variable instead of the exact initial average when disturbances persist. A decentralized-gradient view introduces a decaying pull toward each node’s initial state and proves almost-sure exact consensus under summability conditions.

Why it matters to the group: The anchoring view is attractive for distributed learning and swarm state because it separates communication noise from state drift without a central corrector.

Follow-up: Replication — simulate packet-level noise and compare convergence, bias and message cost for anchored and ordinary consensus.

6. KV spectra show which axes actually compress

LLM KVHigh priorityarXiv preprintSeptember 23, 2026

Timeliness: Fresh signal · current research window

Trend / relevance: A systematic format comparison replaces generic low-rank intuition with measured spectra across heads, tokens, features and layers.

Token and feature modes carry useful low-rank structure, while head and grouped-layer modes remain nearly full rank at practical error levels. Tucker decomposition performed best from two- to five-times compression, but keys and values preferred different representations; post-RoPE keys also lost substantial compressibility.

Why it matters to the group: A communication-aware cache compressor should preserve resistant axes and decide differently for keys and values instead of applying one uniform rank budget.

Follow-up: Prototype — transmit Tucker factors for values and a two-dimensional key factorization, then measure bytes, reconstruction error and downstream task loss.

7. KV eviction becomes a finite-sample risk contract

Timeliness: Fresh signal · current research window

A post-hoc procedure selects a cache-retention policy that satisfies a target degradation risk and confidence requirement, with full-KV fallback when no compressed policy is certified. 12. AirGC-CD makes clipped over-the-air aggregation exactly debiasable

Timeliness: Still timely · six-day-old over-the-air learning result

A partial Gaussian-circulant precoder makes each local update Gaussian before clipping, allowing a closed-form Bussgang correction that removes bias and leaves variance. The same linear map compresses a dimension-d update to m channel uses with fast-Fourier-transform complexity.
